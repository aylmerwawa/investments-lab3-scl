# 投资学实践 3：估计证券特征线（SCL）

北京师范大学 2026 秋季学期。主计算在 `分析.py`，题面之外的拓展分析在 `拓展.py`（二者合起来与 `作业.ipynb` 等价，后者已执行并保留输出），报告正文是 `报告.qmd`。

## 做了什么

五只来自不同行业的 A 股（中信证券、立讯精密、紫金矿业、五粮液、长江电力），以沪深 300 为市场代理，窗口 2021-10-01 至 2026-09-30，估计证券特征线并做方差分析；月度为主，周度、日度对照；估计 SML。拓展：稳健标准误与自助法、$\beta$ 稳定性与 Blume 调整、$\alpha$ 转移对冲、等权组合分散化、市场代理敏感性、绩效指标。

## 数据

CSMAR 三份文件放到 `data/` 下（**不进 git**，受使用授权限制）：

- 日个股回报率文件 `TRD_Dalyr.csv`（考虑现金红利再投资的日个股回报率 `Dretwd`）
- 指数文件 `TRD_Index.csv`（沪深 300，`Indexcd=000300`，`Retindex`）
- 无风险利率文件 `TRD_Nrrate.csv`（一年期整存整取 `NRI01`，日度化 `Nrrdaydt`，单位为 %）

另有公司文件 `TRD_Co.csv` 仅用于选股时核对上市日期与行业，脚本不读取。

## 运行

conda 环境 `ml`（pandas / numpy / scipy / statsmodels / matplotlib）。

```bash
python 分析.py            # 主分析
python 拓展.py            # 拓展分析（会先载入 分析.py）；或在 jupyter 中运行 作业.ipynb
quarto render 报告.qmd --to pdf
```

表和图写入 `结果/`，命名与题号对齐：`00` 数据概览，`01` 特征线回归（月、周、日），`02` 方差分析，`03` 残差相关，`04` SML，`05` 自检，`06`–`11` 拓展分析；图为 `fig-01` 至 `fig-06`。
